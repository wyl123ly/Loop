回路 Loop v0.6.0 · Windows 原生版（纯 Flutter）
============================================

怎么用
------
1. 双击 Loop.exe（整个文件夹一起保留，别只拷 exe）
2. 原生 Flutter 窗口直接打开，没有浏览器、没有 Python、没有后台子进程
3. 关闭窗口 = 退出

第一次在「设置」里填 DeepSeek API Key。

v0.6.0 新功能
-------------
- 独立回答浮窗：在主窗口提交非空问题后，回答显示在独立的第二顶层窗口；主窗口仍是聊天/流式/数据库唯一来源，回答窗只读。
- 回答窗宽度约工作区 35%（逻辑 420–900），高度随回答自适应，最小 180、最大 760 逻辑像素；到上限在窗内滚动。回答窗可拖动、收起、关闭、替换，不遮挡主窗输入条。
- 极简形态：浮窗缩到最小时，或点浮窗右上角最小化按钮，会变成 460×52 的紧凑条，只保留输入、截图、返回三要素；始终置顶、整条可拖动，返回/展开恢复浮窗。
- 点击回答窗、拖标题、滚动条、滚轮不会抢走主窗口输入焦点；亮/暗主题即时同步；125%/150% 多显示器下回答窗尺寸/位置/DPI 正确。

文件夹里都是什么
----------------
Loop.exe                       原生 Flutter 界面
flutter_windows.dll            Flutter 运行时
sqlite3.dll / pdfium.dll       本地数据库与 PDF 解析（进程内加载）
pdfrx_pdfium_gate.dll          PDF 访问保护
desktop_multi_window_plugin.dll 第二顶层回答窗
data\                          界面资源（字体、app.so 等）
version.json                   版本校验文件
使用说明.txt

数据在哪
--------
按顺序找第一个存在的 data 文件夹：
1. 环境变量 LOOP_DATA_DIR
2. Loop.exe 同级 data\loop.db
3. 上一级 data\
4. 上两级 data\
5. %LOCALAPPDATA%\Loop\data

日志：<数据目录>\loop.log（只有异常时才写）

后端在哪
--------
后端已经用 Dart 重写，跑在同一个进程里（HTTP 127.0.0.1:8765），
SQLite 数据库、全文检索、PDF/DOCX/PPTX 解析、DeepSeek 调用都在进程内完成。
启动不需要拉起 Python 或任何子进程，所以是秒开。

已知限制
--------
- 第二引擎冷启动使回答窗首次出现约 1.0–1.1 秒（已作为 accepted EXCEPTION 记录）；期间主窗口会显示“正在思考…”且输入不中断。
- 真实中文 IME 组合、100% DPI 显示器、物理拔插显示器、可见任务栏场景未在真机全矩阵覆盖；相关逻辑有单元测试，建议人工复测。
- 双击回答窗标题恢复自动位置的行为已移除（本版不提供该行为）。
- 回答窗首次创建依赖第二 Flutter 引擎；若系统拦截/环境异常，会回退为不创建并保留主窗会话。

出问题
------
- 提示端口 8765 被占用：关掉另一个 Loop 实例（或旧的 start.bat 服务）
- 首次运行可能被 SmartScreen 拦截：更多信息 → 仍要运行（未签名）
- 上传 PDF 解析失败：扫描件没有文字层，请改用截图提问
- 回答窗异常：关闭回答窗后再提交；主窗口会话与数据不受影响
