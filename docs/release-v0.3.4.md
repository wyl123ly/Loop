# Loop v0.3.4

## 性能修复
- 修复拖拽缩放窗口时的卡顿。
- 原因一：Aurora 背景有 4 个全屏级高斯模糊光斑，缩放时持续重新合成。
- 原因二：每个玻璃面板都有 BackdropFilter，拖拽时叠加多层模糊。
- 原因三：窗口宽度变化会触发 Shell 重建，连带重建所有页面。
- 修复：
  - 光斑改为径向渐变，去掉 ImageFiltered。
  - 拖拽期间玻璃面板切换为纯色、跳过阴影，松手后恢复。
  - 侧栏宽度监听下移到独立组件，缩放不再重建整个页面树。
- 实测拖拽阶段 64 帧：总耗时 p50 10.8ms / p95 14.8ms / p99 21.6ms。

## 升级
- 从 v0.3.3 启动时会收到自动更新提示。
- 也可以直接下载 `Loop-Desktop-win64.zip` 覆盖程序目录；`data` 用户数据会保留。
