# Loop v0.3.1

首个带自动更新能力的测试版本。

## 自动更新
- 设置页新增「检查更新」，支持 GitHub Release 版本比较。
- 启动时自动检查新版本，弹窗可稍后。
- 下载后校验大小与 SHA-256，校验 `version.json` 与 Release 版本一致。
- 下载完成后由 PowerShell 助手替换程序并重启，保留资料库与笔记。
- 更新失败自动回滚旧版本。

## 资料
- 支持导入整个文件夹，保留目录层级。
- 文件夹和子目录可逐层展开/收起。
- 批量导入不限文件数量，进度可取消。
- 删除大文件夹改为批量清理，实测 121 个文件约 0.07 秒。

## Agent
- 计划卡、逐次审批、停止、运行持久化。
- 文件系统读写、Shell、浏览器、MCP、多 Agent 委派。
- 代理页：权限、MCP 管理、审计、后台定时任务。
- 后台任务、托盘常驻、开机自启。

## 界面
- 深色主题关键词改为淡紫标签，中英文分别适配字体。
- 保留浅色/深色两套主题与现有笔记、资料、待办布局。

## 安装
下载 `Loop-Desktop-win64.zip`，解压后运行 `Loop.exe`。
