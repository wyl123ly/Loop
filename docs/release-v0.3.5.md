# Loop v0.3.5

## 修复 Agent 卡在验证步骤
- 重现原因：一次「检索 + 写笔记」用了 12 次工具调用（8 次检索、2 次计划、1 次写笔记、1 次回读），正好撞上旧的 12 次上限，没有预算再更新计划或给出结论，计划卡在 in_progress。
- 工具预算从 12 次提升到 24 次，最大轮次从 12 提升到 20。
- 写工具成功返回 note_id / committed，明确告知模型「已写入，无需重复确认」。
- 写入成功后自动把计划中对应的写步骤标记为 done。
- 同一工具 + 同一参数重复调用直接跳过；连续重复 2 次强制结束。
- 正常结束或达到上限时自动收尾计划：in_progress → done，pending → skipped，不再停在 in_progress。
- 系统提示改为「写成功即完成，不要反复回读确认」；只有失败或用户要求时才读一次。
- 达到上限/重复时若没有最终文字，自动补一条「已完成…已停止重复验证」并推送到界面。

## 验证
- 模拟 12 步「检索 → 写笔记」：完成，计划无 in_progress。
- 模拟连续 3 次 list_notes：后两次 skipped，笔记只写一次，计划自动收尾。
- flutter analyze 0 issues；10 个测试通过。
