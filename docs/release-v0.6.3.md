# Loop v0.6.3

## 修复
- 极简模式提问时进程卡死/CPU 持续升高。
- 根因：为回答窗消除黑色圆角而加的 `SetWindowRgn` 在 `WM_SIZE` 中被递归触发，持续刷新窗口区域，形成消息循环。
- 修复：圆角区域更新增加重入保护，并对窗口尺寸/DPI 做去重；仅在尺寸或 DPI 实际变化时调用 `SetWindowRgn`。
- 保留 v0.6.1 的圆角黑块修复和 v0.6.2 的“仅极简形态创建回答窗”限制。

## 验证
- 极简模式真实流程：提交问题 → 回答窗出现 → 数据库写入回答；修复前 CPU 约 3.4→7.9 持续增长，修复后稳定约 4.1。
- flutter analyze 0 issues；flutter test 262/262；Windows release 构建通过。

## 升级
- 从 v0.6.2 启动时会收到自动更新提示。
- 也可以下载 `Loop-Desktop-win64.zip` 覆盖程序目录；用户 `data` 会保留。
