## 0. 一句话架构

**Flutter 客户端（Windows / Web）+ 本地 FastAPI 服务 + SQLite 单文件 + DeepSeek API。**

```
Flutter (Flutter Web 构建产物，由后端静态托管)
        │  HTTP / SSE  localhost:8765
        ▼
FastAPI  ── SQLite (data/loop.db) + 附件目录 (data/files)
        │  HTTPS
        ▼
DeepSeek API (flash / v4-pro)
```

一个进程、一个端口、一个数据库文件。启动 `start.bat` → 浏览器打开 `http://127.0.0.1:8765`。

## 1. 关键决策（以及为什么）

| # | 决策 | 选项 | 选择与理由 |
|---|---|---|---|
| 1 | 前端 | Flutter / React | **Flutter**（用户指定）。同一套代码可出 Windows 桌面 + Web preview |
| 2 | 后端 | 纯客户端直连 / 本地服务 | **本地 FastAPI**。三个理由：① 浏览器直连 DeepSeek 会被 CORS 拦；② PDF/PPTX 解析在 Python 里最成熟；③ API Key 不落在前端，SQLite 也好备份 |
| 3 | 数据库 | SQLite / JSON 文件 | **SQLite**（Python 内置 sqlite3）。单文件、可导出、支持 FTS5 |
| 4 | Agent | LangChain / 手写循环 | **手写工具循环**（OpenAI 兼容 function calling）。约 150 行，完全可控，出问题好查 |
| 5 | 复习 | 自研 / ts-fsrs 思路 | **FSRS-4.5 简化实现**（Python，约 90 行）+ 单元测试。后续可换官方参数 |
| 6 | 检索 | 向量 / 关键词 | **FTS5 + 中文 bigram**，零依赖、零成本。资料量大再上向量（sqlite-vec） |
| 7 | 桌面打包 | 现在 / 之后 | **之后**。Windows 原生构建需要 VS C++ 工具链（约 3GB，需管理员），当前机器没有；先用 Web 跑通，装好 VS 后 `flutter build windows` 即可 |

> ⚠️ 当前机器没有 Flutter SDK、没有 Visual Studio C++ 工具链，也没有管理员权限。
> 所以 Demo 以 **Flutter Web** 形态运行（同一份 Flutter 代码），桌面构建按第 9 节操作。

## 3. 数据模型

```sql
subjects(id, name, goal, exam_date, color, created_at)
conversations(id, subject_id, title, mode, created_at, updated_at)
messages(id, conversation_id, role, content, steps, refs, model,
         tokens_in, tokens_out, created_at)
materials(id, subject_id, name, kind, path, status, pages, chars, created_at)
chunks(id, material_id, page, text)
chunks_fts(text)                        -- FTS5，存 bigram 串
cards(id, subject_id, type, front, back, tags, source_ref,
      due, stability, difficulty, reps, lapses, state, last_review,
      suspended, created_at)
reviews(id, card_id, rating, reviewed_at, scheduled_days, elapsed_days)
tasks(id, subject_id, title, due, estimate_min, status, created_at, done_at)
notes(id, subject_id, title, body, source_ref, created_at)
settings(key, value)
usage(id, ts, model, tokens_in, tokens_out, cost)
```

约定：
- 时间统一 ISO8601 带时区（本地时区 Asia/Shanghai），存字符串。
- `cards.state`：0 新卡 / 1 学习中 / 2 复习中 / 3 重新学习。
- `messages.steps`：JSON 数组，记录工具调用步骤（前端渲染成时间线）。
- 删除资料时级联删除 chunks（FTS 用触发器同步）。

### 4.1 `/api/chat` 的 SSE 协议

请求：
```json
{"conversation_id": 1, "subject_id": 2, "text": "这题怎么做",
 "attachments": ["mat_3", "up_7"], "mode": "answer"}
```

响应（`text/event-stream`，每条 `event:` + `data:`）：
```
event: step
data: {"name":"检索资料","status":"running"}

event: step
data: {"name":"检索资料","status":"done","detail":"命中 3 段"}

event: delta
data: {"text":"特征值刻画的是"}

event: done
data: {"message_id": 42, "tokens_in": 3120, "tokens_out": 640, "cost": 0.0031}

event: error
data: {"message":"API Key 无效"}
```

前端按 `\n\n` 切块，识别 `event:` 与 `data:` 两行。

## 5. DeepSeek 接入

| 项 | 值 |
|---|---|
| Base URL | `https://api.deepseek.com`（OpenAI 兼容） |
| 默认模型 | `deepseek-flash`（支持视觉 + 工具调用，1M 上下文） |
| 强推理模型 | `deepseek-v4-pro`（不支持视觉） |
| 流式 | `stream=true`，解析 `data:` 行 |
| 图片 | `content: [{type:"text"},{type:"image_url",image_url:{url:"data:image/png;base64,..."}}]` |
| 工具 | `tools=[{type:"function",function:{...}}]` |
| 缓存 | 稳定前缀（系统提示 + 科目画像）放最前，天然命中 |

计费：`cost = in*price_in + out*price_out`，价格按 UTC 判断高峰（01–04、06–10 UTC 为高峰，单价 ×2），价格表放 `llm.py` 常量，可改配置。

重试：429/5xx 重试 2 次（指数退避）；401 直接报"API Key 无效"；超时 120s。

## 6. Agent 工具

系统提示词固定输出结构：结论 → 推导 → 例子 → 自测题 → 来源。

| 工具 | 参数 | 行为 |
|---|---|---|
| `search_materials` | `query` | FTS5 检索当前科目资料，返回带 `material_id/page` 的片段 |
| `create_cards` | `cards:[{front,back,type}]` | 写入 `cards`，去重（front 相似度） |
| `create_tasks` | `tasks:[{title,due,estimate_min}]` | 写入 `tasks` |
| `create_note` | `title, body` | 写入 `notes` |
| `plan_exam` | `exam_date, daily_minutes, topics[]` | 按天倒排生成任务 |

循环：`模型 → tool_calls? → 执行 → 回填 → 模型`，最多 4 轮；每轮发出 `step` 事件；工具结果 JSON 回填，模型最后给自然语言总结。

写入类工具统一返回 `{ok, ids}` 并在 `steps` 里记录，前端展示"已创建 N 项 · 撤销"（撤销 = `DELETE` 对应 id，Demo 里用"撤销"按钮直接调用删除接口）。

## 7. 检索

```
文件 → 文本抽取 → 清洗 → 分块（800 字，重叠 100，按段落边界切）
     → bigram 分词（中文按二字切，英文按词）→ chunks + chunks_fts
查询 → BIGRAM(query) → FTS5 MATCH（OR 连接）→ BM25 排序 → Top-5 → 截断到 2000 字
```

> 为什么不用向量：个人语料 < 50 份文档时，bigram + BM25 的召回已经够用，且零依赖、零延迟。
> 何时换：单科目资料 > 30 份、或用户抱怨"搜不到"时，再加 sqlite-vec + bge-small-zh。

## 8. 复习调度（FSRS-4.5 简化版）

参数 `w[0..16]` 使用 FSRS-4.5 默认值。核心公式：

- 初始稳定度 `S0(G) = w[G-1]`
- 初始难度 `D0(G) = clamp(w[4] - exp(w[5]*(G-1)) + 1, 1, 10)`
- 可提取性 `R(t,S) = (1 + 19/81 * t/S)^(-0.5)`
- 成功回忆 `S' = S * (1 + exp(w[8]) * (11-D) * S^(-w[9]) * (exp((1-R)*w[10]) - 1) * hard * easy)`
- 遗忘 `S' = w[11] * D^(-w[12]) * ((S+1)^w[13] - 1) * exp((1-R)*w[14])`
- 间隔 `I = S/FACTOR * (r^(1/DECAY) - 1)`，目标留存 `r=0.9`

评分映射：1 Again / 2 Hard / 3 Good / 4 Easy。新卡 Again 进"重新学习"，间隔约 1–10 分钟（Demo 简化为当天再来）。

单元测试覆盖：四档间隔单调递增、遗忘后稳定度下降、难度边界 [1,10]。

## 9. 运行与构建

### 9.1 现在就能跑（Flutter Web）

```bat
start.bat
```
做三件事：起 uvicorn（8765）→ 若 `server/web` 不存在则提示先构建 → 打开浏览器。

手动：
```bat
cd server
python -m pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8765
```

### 9.2 构建 Flutter 产物

```bat
cd app
flutter pub get
flutter build web --release
xcopy /E /I /Y build\web ..\server\web
```

### 9.3 打成 Windows 桌面（需要一次性的环境安装）

1. 装 [Visual Studio Build Tools](https://visualstudio.microsoft.com/downloads/) → 勾选 **Desktop development with C++**（约 3GB，需管理员）。
2. `flutter doctor` 显示 Visual Studio ✓。
3. `cd app && flutter build windows --release` → exe 在 `build\windows\x64\runner\Release\`。
4. 桌面版仍连本地 `127.0.0.1:8765`（后端可后续用 PyInstaller 打包成 sidecar）。

## 11. Demo 范围与已知限制

**做**：多模态对话（文字/图片/PDF/DOCX/PPTX/TXT）、流式输出、工具步骤、生成卡片/出题/笔记/待办、FSRS 复习、今日聚合、资料库、科目、用量统计、设置。

**不做**：语音、云同步、多用户、移动端原生、知识图谱、向量检索、卡片导出 APKG。

**已知限制**：
- Flutter Web 首次加载需下载 CanvasKit（约 2MB），之后走缓存。
- 扫描版 PDF（图片型）没有文字层，需走"截图提问"。
- 单用户、无鉴权，仅监听 `127.0.0.1`。
- FSRS 参数未按个人数据优化（需要 200+ 条复习日志）。

## 13. 实现说明（2026-10-22 落地版）

| 项 | 设计 | 实际 |
|---|---|---|
| 前端 | Flutter | Flutter 3.47.7（Web 产物 + Windows 工程骨架），Material 3 |
| 后端 | FastAPI | 0.115.6 + uvicorn，单进程 |
| 数据库 | SQLite | 标准库 sqlite3 + WAL + FTS5 |
| 复习 | FSRS-4.5 | Python 移植（`server/fsrs.py`），10 个单测 |
| 检索 | bigram + FTS5 | 与设计一致，chunk 800 字 / 100 重叠 |
| 字体 | 未提 | **内置 2.4MB Noto Sans SC 子集**：CanvasKit 的中文回退依赖 fonts.gstatic.com，国内网络会显示豆腐块，必须自带 |
| 调试 | 未提 | `?tab=N` 直达页签；`.tools/mock_llm.py` 假模型服务，可离线验证工具循环 |

**已验证**
- 后端 10 个 pytest 全过（FSRS 四档单调、遗忘降稳定度、bigram 检索、页码、科目过滤）
- 前端 `flutter analyze` 0 issues，4 个解析测试通过
- 端到端（mock 模型）：流式 tool_calls → 建 2 张卡 → 第二轮回答 → `done` 带 usage；卡片立即进入复习队列
- 错误路径：无 Key / 假 Key → SSE 返回可读中文错误，不崩溃
- 界面：5 个页面截图（`docs/screenshots/`）

**与设计的偏差**
1. 生成卡片/出题/笔记/任务走独立 REST 接口（按钮触发），不只靠 Agent 工具——更可控、不占对话轮次；Agent 里仍保留同名工具。
2. `plan_exam` 直接按天生成任务，没做甘特图拖拽。
3. 撤销未实现：写操作只能删除，没有统一 undo token（P1）。
4. 图片只作为单轮附件，不做图片库。
