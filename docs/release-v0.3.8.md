# Loop v0.3.8

## 修复截图窗口与标题栏
- 原因：`window_manager.setFullScreen()` 在无边框窗口下不会真正调整窗口，但退出全屏时会恢复 Windows 原生窗口样式，导致：
  - 截图选框没有铺满屏幕；
  - 截图完成后出现 Windows 自带标题栏。
- 修复：
  - 移除 `setFullScreen`。
  - 保存原窗口 bounds，截图期间用 `setBounds` 铺满主屏并置顶。
  - 完成/取消后恢复原 bounds 或最大化状态。
  - 不再改动窗口样式，Loop 自绘标题栏保持不变。
- 实测：截图期间窗口 bounds 为 0,0 / 2048×1152 逻辑像素，输出 2560×1440 PNG；恢复后回到原位置和大小。

## 升级
- 从 v0.3.7 启动时会收到自动更新提示。
- 也可以直接下载 `Loop-Desktop-win64.zip` 覆盖程序目录；`data` 用户数据会保留。
