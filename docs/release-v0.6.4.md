# Loop v0.6.4

## 修复
- 极简模式图标悬停文字显示不全。
- 原因：52px 高的极简窗口裁掉了系统 Tooltip 的浮层。
- 修复：改为极简条内部的悬停标签浮层，完整显示文字，不改变窗口尺寸、不抢焦点、不引入定时器或窗口消息循环。
- 覆盖截图、返回主窗口、拖动/展开、附件等图标；发送/停止仍保留按钮语义。

## 提交卡顿复核
- 极简提交后第二回答窗口首次创建约 1.0–1.1 秒（真实复测 1029–1037ms），属于第二 Flutter 引擎冷启动。
- 该等待期间主窗口进入发送/思考态，不是进程死锁；v0.6.3 已修复 SetWindowRgn 递归导致的真正卡死。
- 后续可考虑在进入极简时预热第二窗口；本次不扩大范围。

## 验证
- flutter analyze 0 issues；flutter test 全量通过（含新增悬停标签测试）。
- Windows release 构建通过。

## 升级
