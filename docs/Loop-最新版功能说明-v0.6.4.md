# Loop 最新版功能说明

> 版本：**v0.6.4**  
> 平台：Windows 10/11 x64  
> 文档时间：2026-10-25  
> 说明：本文覆盖正式版当前已交付功能；插件模块仅存在于独立测试版 `Loop-Test`，不属于正式版。

---

## 1. 产品定位

Loop（回路）是一个 Windows 桌面 AI 学习/工作台：

- 以聊天为入口，同时管理资料、待办、笔记
- 支持 Agent 工具调用、文件/浏览器/MCP、多 Agent、后台任务
- 支持桌面截图、图片提问、流式回答、桌面答疑悬浮窗
- 所有数据保存在本机 SQLite，模型默认使用 DeepSeek
- 便携版，无需安装

---

## 2. 快速开始

1. 解压 `Loop-Desktop-win64.zip`
2. 双击 `Loop.exe`
3. 打开「设置 → DeepSeek 接入」
4. 填入 API Key，必要时修改 Base URL / 模型
5. 点「测试连接」
6. 回到「对话」开始提问

默认数据目录：

```text
%LOCALAPPDATA%\Loop\data
```

可通过环境变量指定其他目录：

```text
LOOP_DATA_DIR
```

升级时保留 `data/loop.db`、`data/files` 等用户数据；程序目录需要可写。

## 3. 窗口形态

### 3.1 普通主窗口

- 无边框、自绘标题栏、圆角
- 可拖拽窗口边缘/四角调整大小
- 最小尺寸 900×600
- 支持最大化/还原、关闭到托盘
- 左侧栏可收起为图标列；窄窗口自动收起
- 布局随窗口宽度自适应，不出现横向滚动

### 3.2 桌面答疑悬浮窗

主窗口标题栏点击「浮窗答疑」进入：

- 默认约 **460×600**
- 最小 **360×420**
- 置顶、可拖动、可缩放、可取消置顶
- 无原生标题栏、无侧栏
- 提供截图、置顶、返回主窗口、关闭按钮
- 与主窗口共用同一个 Flutter 进程、同一个 `ChatScreen` State、当前会话、附件和 SSE
- 流式回答中切换形态不会中断
- 返回主窗口后仍是同一会话和同一段回答
- 最大化状态进入浮窗后返回，能恢复原普通窗口位置/大小；再点「还原」也回到原 normal 位置

### 3.3 极简形态

浮窗缩到最小，或点浮窗「最小化」按钮后：

- 变成 **460×52** 紧凑条
- 只保留：
  - 输入框（含发送/停止）
  - 截图
  - 返回
- 无消息区、无页头、无侧栏、无留白
- 置顶、整条可拖动
- 左侧 Logo/拖动区双击可展开回普通浮窗
- 图标悬停使用条内浮层显示完整文字，不受 52px 高度裁切
- 返回：退出浮窗到主窗口
- 展开：恢复普通浮窗

### 3.4 独立回答浮窗

当前正式版仅在**极简形态**提交非空文本时创建：

- 独立的第二顶层窗口，不是主窗口内嵌面板
- 主窗口是聊天/SSE/数据库唯一数据源
- 回答窗只读，通过本地 IPC 接收 snapshot/delta/status/theme
- 宽度固定为工作区约 **35%**（逻辑 420–900）
- 高度随流式正文自适应：
  - minH **180**
  - maxH **min(70%, 760)**
  - 达上限后内部滚动
  - 80ms 合并节流
- 自动就近放在输入条上方，与输入条保持 gap，零遮挡
- 可拖动、收起、关闭、替换
- 关闭/收起不影响主窗口会话
- 普通窗口、普通浮窗中提问**不会**创建回答窗
- 退出极简形态时自动关闭回答窗

### 3.5 快捷键

| 快捷键 | 功能 |
|---|---|
| `Alt+Q` | 切换主窗口/浮窗（全局） |
| `Alt+A` | 进入截图（全局） |
| `Enter` | 发送 |
| `Shift+Enter` | 换行 |
| `Esc` | 取消截图选框 |

说明：

- 全局快捷键可能被其他程序占用（如游戏/安全软件，常见 RegisterHotKey 1409）
- 冲突时自动降级为按钮操作，不影响启动和使用
- 被占用时 tooltip 会提示

## 4. 对话

### 4.1 流式输出

设置 → 对话与模型 → 流式输出：

- 默认开启：回答逐字显示
- 关闭：等待完整回复后一次性显示
- 工具步骤、计划、审批仍实时
- 切换对下一条消息生效
- 状态保存到 SQLite，重启/升级保留

### 4.2 Markdown 与公式

- Markdown 标题、列表、引用、表格、代码块
- KaTeX 数学公式（行内/块级）
- 加粗、斜体、链接内部递归解析：
  - `**$r(A)$ = $A$**` 可正常渲染
  - 兼容 `\$...\$` 转义公式
- 代码块/表格过宽时横向滚动
- 深色/浅色主题适配

### 4.3 图片与附件

- 上传图片、PDF、DOCX、PPTX、TXT、MD
- 图片可作为问题上下文发给模型
- 输入框附件区显示图片缩略图
- 发送后的用户消息内保留附件预览
- 点击缩略图打开大图：
  - 支持缩放、拖动
  - 关闭返回
- 文档解析后进入资料库
- 单个上传或整文件夹导入：
  - 保留目录层级
  - 不限文件数
  - 进度显示、可取消
  - 重复文件可跳过/更新
  - 删除文件夹同时清理索引和副本

### 4.4 会话

- 多会话历史，左侧「最近对话」切换
- 每个会话独立上下文
- 支持复制 Markdown
- 回答可一键：
  - 存笔记
  - 加待办
- 显示工具步骤、计划、引用、token/cost
- 支持停止生成

### 4.5 聊天内截图

- 输入框截图按钮，两种模式：
  - 直接截图（包含 Loop）
  - 隐藏 Loop 后截图
- 全屏拖拽框选
- 完成/取消/重截
- 自动裁切为 PNG，上传为 `img_` 附件
- 截图结束恢复原窗口形态
- 浮窗内截图默认隐藏 Loop
- 支持当前显示器 + 多显示器/DPI 定位

## 8. Agent

### 8.1 计划与执行

- 计划卡：自动拆步骤，实时更新 pending/in_progress/done/skipped
- 工具调用步骤展示
- 写入成功自动完成对应计划，不再反复确认
- 工具调用预算 24 次、最多 20 轮
- 重复工具调用跳过
- 终止时自动收尾计划，避免卡在“进行中”
- 可随时停止运行

### 8.2 工具能力

- 资料检索（RAG）
- 待办
- 笔记
- 工作区文件读写
- Shell
- 浏览器
- MCP 工具

### 8.3 浏览器

- 本地 Edge 打开网页
- 读取页面
- 点击
- 输入
- 截图
- 适合查资料、读文档、操作网页

### 8.4 MCP

- 支持 stdio / Streamable HTTP MCP 服务器
- 可手动添加第三方 MCP 服务器
- 工具调用逐次审批
- 启用/禁用/测试连接

### 8.5 多 Agent

- 将只读研究、分析、审阅任务委派给子 Agent
- 子 Agent 结果回传主 Agent 继续总结
- 适合长资料/多角度分析

### 8.6 审批与审计

- 所有危险操作在聊天中逐次审批
- 可允许/拒绝
- 审计页记录运行与工具调用
- 可随时停止
- 危险操作必须经用户审批

### 8.7 代理页

- 工作区路径
- 能力开关
- MCP 管理
- 审计记录
- 后台任务

### 8.8 后台任务

- 按间隔运行
- 每天定时运行
- 应用/托盘运行期间生效
- 任务可管理
- 不影响前台聊天

## 10. 自动更新

- 从 GitHub Release 读取最新版本和更新说明
- 下载到 `%LOCALAPPDATA%\Loop\updates`
- 校验文件大小与 SHA-256
- 解压后校验 `version.json` 与 Release 版本一致
- PowerShell 助手等待旧进程退出
- 替换程序文件后重启
- 保留 `data/loop.db`、`data/files`
- 失败自动回滚
- 无网络时提示错误，并保留手动下载入口

发布约定：

- tag：`vX.Y.Z`
- 附件：`Loop-Desktop-win64.zip`
- ZIP 必须含 `Loop.exe` 和 `version.json`

## 11. 数据与隐私

- 本地 SQLite 数据库：`data/loop.db`
- 附件/资料副本：`data/files`
- API Key 只在本机，不上传第三方
- 后端仅监听 `127.0.0.1:8765`
- 截图、图片、资料只在用户动作时上传到本地后端/模型
- 安装/更新不覆盖用户数据
- MCP/第三方工具属于第三方程序，启用前需确认信任来源
- 测试版插件 MCP 子进程使用最小环境白名单，不继承 API Key/LOOP_* 等敏感变量（正式版无插件模块）

## 13. 已知限制

- 独立回答窗首次创建约 **1.0–1.1 秒**（第二 Flutter 引擎冷启动，accepted EXCEPTION），期间主窗口有“正在思考…”反馈
- 极简模式提交时仍会有这段冷启动等待；可后续做进入极简时预热
- 全局快捷键可能被其他程序占用（1409），冲突时按钮可用
- 真实中文 IME 组合、100% DPI、物理拔插显示器、可见任务栏全矩阵尚未完全真机验证
- 真实鼠标点击部分依赖 widget/API/截图验证，不能完全替代人工
- GitHub 网络不可达时自动更新/Release 发布会失败
- 双击回答窗标题恢复自动位置的行为已移除
