# Loop v0.6.2

## 修复
- 普通窗口或普通浮窗中提交问题，不再创建独立的“回答浮窗”，避免第二窗口置顶遮挡输入、造成卡住。
- 回答浮窗严格限制在极简形态：只有极简条中提交非空文本才创建。
- 从极简形态展开回普通浮窗或返回主窗口时，自动关闭回答浮窗；回答记录仍完整保留在主聊天。

## 验证
- 新增回归测试：普通浮窗提交只走主聊天，不调用回答窗 sink；极简形态提交仍正常创建回答窗。
- flutter analyze 0 issues；flutter test 全量通过。
- Windows release 构建通过。

## 升级
- 从 v0.6.1 启动时会收到自动更新提示。
- 也可以下载 `Loop-Desktop-win64.zip` 覆盖程序目录；用户 `data` 会保留。
