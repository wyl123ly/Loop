# Loop v0.3.9

## 图片附件预览
- 输入框附件区：
  - 图片显示 66×66 缩略图，右上角可移除。
  - 点击缩略图打开大图预览。
- 发送后的用户消息：
  - 图片以缩略图显示在气泡内。
  - 点击打开大图，支持缩放、拖动、关闭。
  - 重新加载对话后仍能恢复图片预览。
- 文件附件显示文件名标签，不强行当图片渲染。

## 数据与接口
- 消息表新增 `attachments` JSON 字段，记录附件 id、名称、是否图片。
- `/api/chat` 写入附件元数据；`/api/messages` 返回解析后的附件列表。
- 图片通过现有 `/api/uploads/<id>` 提供，不复制文件。
- 旧消息没有附件数据时默认为空列表。

## 验证
- 上传 8×8 PNG，发送带附件消息后，消息接口返回：
  `attachments=[{id:img_4,name:preview-test.png,is_image:true}]`
- 图片 URL 返回 `200 image/png`。
- Message 解析附件单元测试通过。
- flutter analyze 0 issues；17 个测试全部通过。

## 升级
- 从 v0.3.8 启动时会收到自动更新提示。
- 也可以直接下载 `Loop-Desktop-win64.zip` 覆盖程序目录；`data` 用户数据会保留。
