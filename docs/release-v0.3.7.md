# Loop v0.3.7

## 新增：聊天内截图
- 输入框左侧新增截图菜单：
  - **直接截图**：截取当前桌面（包含 Loop）。
  - **隐藏 Loop 后截图**：先隐藏窗口，截取干净桌面。
- 截图后进入全屏选框：
  - 鼠标拖拽选择区域
  - 「全屏」一键选择整屏
  - 显示选区宽高
  - Esc 或「取消」退出
- 确认后自动裁切，作为 PNG 图片附件加入当前消息。
- 截图可继续输入文字后一起发送，走现有图片提问链路。
- 截图完成后恢复原窗口大小、位置、最大化和置顶状态。

## 验证
- 截图脚本独立测试通过，能生成 PNG。
- 选框组件测试通过：拖拽后「完成」可用，取消可退出。
- flutter analyze 0 issues；17 个测试全部通过。
